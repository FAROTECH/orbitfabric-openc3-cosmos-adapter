# OpenC3 COSMOS Target Compatibility

Target compatibility is separate from OrbitFabric Core conformance.

The CI target-compatibility control uses the validated OpenC3 COSMOS `v7.3.0` source baseline and verifies that generated Python procedure/suite artifacts use APIs and syntax present in that downstream baseline.

The historical PoC retains the stronger local full-runtime Docker/TCP/CTRF experiment. A hosted-CI live COSMOS runtime is not claimed until a reliable topology is established.
